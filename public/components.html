The reusable pieces of the Netlify web experience. Use a component as it is before making something new, and if you need a variation, add it to the library so everyone benefits.

Buttons

Primary (sky) is the one action you want people to take, so use one per view. Secondary is for the next most important action. Tertiary covers everything else. All buttons are pill-shaped, 40px tall, with UI / Button text.

Icon buttons

40px circles for compact actions like carousels and close. Always give them an accessible name.

Labels, chips & badges

Chips filter and categorize. Badges flag status in UI / Badge type. Badge fills use accent containers, which switch to a dark fill with colored text in dark mode.

Tabs

Pill tabs switch views and prompt modes. The indicator slides between options using the Guide preset (Settle, 240ms). Labels use UI / Tab.

Case study selector

A vertical list for switching between examples. The active row expands to show a short description.

Accordion

For FAQs and long lists of detail. Expands with the Arrange preset (Settle, 360ms).
