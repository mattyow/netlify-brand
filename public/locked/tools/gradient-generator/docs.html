REST API · v1

Brand gradients, on request

Render any gradient from the generator as WebP, JPEG or PNG, up to 4K. Get its settings and the right text color as JSON, or a live animated embed, straight from your own apps and scripts.

Getting started

All endpoints live under /api/v1. Ask the generator's owner for the shared API key, then make your first request:

curl -H "Authorization: Bearer $GRADIENT_KEY" \
  "{origin}/api/v1/gradient?preset=5&size=og&output=webp" -o gradient.webp

That saves preset 5 as a 1200×630 social card in WebP. Swap preset for random=anything, or send your own colors and mode.

Authentication

Every endpoint except GET /api/v1 needs the key. Send it in either header:

Authorization: Bearer <key>
X-API-Key: <key>
Keep the key on your server. Browser apps on other domains can call the API, but a key used in a web page can be read by anyone who opens that page.

Usage and limits

License

The shared key is licensed for internal Netlify brand work only. Don't publish it, put it in public client-side code, or pass it to third parties. Use brand palette colors in any combination you like. The presets are starting points, not rules. Add strict=true to reject colors outside the palette.

Rate limit

120 requests per minute per client IP address. Requests over the limit get HTTP 429; wait a minute and retry. Ask the generator owner if you need a higher limit or your own key.

Fair use

Render each image once and keep it. Deterministic responses are immutable and carry an ETag, so revalidating with If-None-Match returns a 304 without rendering. To render preset grids, use one batch call instead of many single requests.

LimitValue
Image sizeUp to 4096 px per side and 9.4 megapixels (3840×2160 and 4096×2160 fit)
Response size20 MB. Very large grainy PNGs can exceed this; use WebP or JPEG.
Render timeAbout 0.1 s for a UI card, 1 s for 1920×1080, 4 s for 4K

Endpoints

GET/api/v1No key

Machine-readable summary of the API, including the usage policy.

GETPOST/api/v1/gradient

Generates one gradient. Returns a PNG unless you choose another output. With GET, pass parameters in the query string. With POST, send them as a JSON object.

curl -H "Authorization: Bearer $GRADIENT_KEY" \
  "{origin}/api/v1/gradient?mode=radial&colors=gold,pink,purple&width=3840&height=2160&output=webp&quality=85" -o slide-4k.webp
curl -X POST "{origin}/api/v1/gradient" \
  -H "Authorization: Bearer $GRADIENT_KEY" \
  -H "Content-Type: application/json" \
  -d '{"mode":"mesh","colors":["ink","lilac","#4e49ff"],"size":"wide","output":"webp"}' \
  -o mesh.webp

Made something you like in the generator? Click Preset JSON under Export and POST the downloaded file as it is. Its gradient and format are used.

format=webp, format=jpeg, format=png and format=svg also work. Image responses include ETag, X-Gradient-Tone, X-Gradient-Text-Color, X-Gradient-Luminance, X-Gradient-On-Brand, X-Gradient-Mode, X-Gradient-Seed, X-Gradient-Width and X-Gradient-Height headers.

Parameters

Collages

GET|POST /api/v1/collage lays out rounded gradient tiles, some with toothed edges, on a white or transparent canvas. The layout and the tile gradients each come from a seed, and the API uses the same seeds as the generator, so a collage you like in the generator can be fetched again by its seeds. Collages default to the 16:9 wide size and to PNG.

curl -H "Authorization: Bearer $GRADIENT_KEY" \
  "{origin}/api/v1/collage?size=wide&count=10&source=presets&layoutSeed=7&gradientSeed=11&output=webp" -o collage.webp

Click Preset JSON while the generator is in Collage mode and POST the file as it is. Its tiles and gradients are used exactly, whatever the seeds.

curl -X POST "{origin}/api/v1/collage?output=svg" \
  -H "Authorization: Bearer $GRADIENT_KEY" -H "Content-Type: application/json" \
  --data @netlify-collage-wide.json -o collage.svg

Collage images carry X-Collage-Tiles, X-Collage-Layout-Seed, X-Collage-Gradient-Seed, X-Gradient-Width, X-Gradient-Height and X-Gradient-On-Brand headers. Collages don't include text, and tiles can't use transparent colors. The tiles together may cover at most 9.4 megapixels.

SVG layers

output=svg works for both /gradient and /collage. It returns the same file as the generator's SVG layers export. A gradient is one named layer, and a collage has an optional background layer plus one clipped layer per tile, named Tile 01, Tile 02 and so on, in stacking order. Motion is built in as SVG animation, so the file loops when opened in a browser. Design tools such as Figma import the first frame and may drop the grain and warp filters. t sets where the animation starts.

curl -H "Authorization: Bearer $GRADIENT_KEY" \
  "{origin}/api/v1/gradient?preset=12&size=og&output=svg" -o gradient.svg

SVG gradients support neither mask, tile nor transparent colors. The text and logo from the generator are not part of API output.

Tone and text color

You don't need to analyze pixels to pick a text color. Every JSON response includes a tone object, and image responses carry the same information in headers:

"tone": {
  "tone": "dark",            // the background: dark → use white text, light → use #131619
  "textColor": "#ffffff",
  "luminance": 0.308,        // average relative luminance, 0 (black) to 1 (white)
  "contrast": { "white": 4.9, "dark": 2.1 },
  "zones": [ { "zone": "top-left", "tone": "light", "textColor": "#131619", "luminance": 0.385 }, … ]
}

contrast uses the generator's own check: the WCAG contrast ratio that 90% of the area reaches for white and for #131619 text. Aim for 4.5 for body text and 3 for large headlines. zones splits the image into a 3×3 grid (top-left first, row by row), so you can pick the color for wherever your text actually sits. On transparent gradients, mostly transparent pixels are ignored. Masks have no tone.

Brand colors and presets

Any combination of brand palette colors is on brand. Pick your own three, in any order, and use transparent wherever you like. Mode, stops, angle and texture are all yours to set.

The 24 presets are the gradient tiles from the brand guidelines. They're good starting points, and their color trios are listed below and at GET /api/v1/preset-colors for inspiration. You don't have to use them.

  • onBrand in JSON responses, and the X-Gradient-On-Brand header on images, are true when every color is from the palette.
  • presetMatch lists the presets that use the same colors. An empty list just means it's your own combination.
  • strict=true rejects colors outside the palette with a 400. It never rejects a combination.
  • presetColors=true with random picks one of the preset trios, if you want something closer to the guidelines.

Preset color trios

Caching

A request is deterministic when it names a preset or a seed (random=some-text) and the same parameters. Deterministic responses never change, so they're sent with:

Cache-Control: private, max-age=31536000, immutable
ETag: "g2-…"

Store the image and the ETag. To check a URL again, send If-None-Match with the ETag: a match returns 304 Not Modified with no body and no rendering. ETags change if the renderer itself changes, so a 200 on revalidation means there's a new image. random=true responses are no-store; ask for output=json to get a reproducible URL for one you want to keep.

Responses are also cached on Netlify's CDN for the same key. A request without the key never sees a cached copy, and the cache is cleared on every deploy.

Transparency and masks

Transparent color stops

Use transparent as any of the three colors to fade the gradient into whatever sits behind it. You get PNG or WebP with an alpha channel (JPEG can't do transparency).

curl -H "Authorization: Bearer $GRADIENT_KEY" \
  "{origin}/api/v1/gradient?preset=2&colors=transparent,green,turquoise&output=webp" -o fade.webp

Masks

mask=true returns a grayscale image with the gradient's shape instead of its colors. For linear, radial, flow and wave, the first stop is black, the second 50% gray and the third white. For mesh, the base is black and the glows are white. Use it as a luminance mask on your own shapes, or as an alpha channel. Set grain=0 for a clean mask.

Tiling

tile=true makes the image repeat seamlessly in both directions, which suits card and page backgrounds. The API renders past the right and bottom edges and cross-fades that margin into the opposite edges. The grain pattern repeats exactly too. Soft gradients (mesh, radial, flow) tile best. A strong linear ramp has to blend back to its start, so expect a soft band near the left and top edges.

curl -H "Authorization: Bearer $GRADIENT_KEY" \
  "{origin}/api/v1/gradient?preset=5&width=512&height=512&tile=true&output=webp" -o tile.webp

Batch

POST /api/v1/batch renders up to 48 gradients (12 megapixels in total) in one call. Send items, each accepting the same fields as /gradient, plus optional defaults applied to every item. Add "kind": "collage" to an item (or send a generator collage export as the item) to render a collage with the /collage fields instead. Batch items default to WebP and can also be SVG. Each result carries its settings, tone, ETag and the image as a base64 data: URI. An invalid item returns ok: false without failing the rest.

curl -X POST "{origin}/api/v1/batch" \
  -H "Authorization: Bearer $GRADIENT_KEY" -H "Content-Type: application/json" \
  -d '{"defaults":{"size":"card","quality":80},"items":[{"id":"p1","preset":1},{"id":"p2","preset":2},{"id":"mine","random":"kit","strict":true}]}'
{ "count": 3, "items": [ { "index": 0, "id": "p1", "ok": true, "etag": "\"g2-…\"", "contentType": "image/webp",
    "bytes": 31810, "data": "data:image/webp;base64,…", "tone": { … }, "gradient": { … }, "urls": { … } }, … ] }

All 24 presets at UI-card size come back in one call in about 2 seconds (around 1 MB). Batch responses aren't cached, so store what you need.

Palette

Use the key (for example cobalt) or the display name (for example Deep teal) anywhere a color is accepted.

Why three colors

Every gradient uses exactly three colors, and that's deliberate:

  • It's the brand system. All 24 gradient tiles in the brand guidelines are three-color, so a palette trio of your own sits naturally beside them.
  • It round-trips. The generator, its Preset JSON export, the HTML embed and the API share one model. A three-color result from the API can be opened, edited and re-exported anywhere; a fourth color would only exist in the API.
  • You can still get variety. Repeat a color (as presets 3 and 17 do) for a band or a symmetric glow, push stops past 0 or 1 to shift the balance, or use transparent to layer two gradients.

Requests with more than three colors get a 400 that points here.
