Color

A restrained neutral base with one accent at a time. Grounded in tech credibility, approachable and deeply human.

Core palette

Layouts sit on white, light grey or off black. Sky is the primary accent and should be used as a light touch: it guides attention, it doesn't fill the page. Click any swatch to copy its hex.

Using color

Every expression should read as a white or light grey background, one accent, and off black text. Only white text goes on off black, as in the web footer.

Semantic tokens

Build with semantic tokens, not raw hex. Each one switches between light and dark mode on its own. These map 1:1 to the Color collection in Figma and tokens.css.

Gradient palette

Gradients bring depth and energy to UI cards, illustration and decoration. Always check contrast: light text on dark gradients, dark text on light ones. The Aa on each tile shows the approved text color.

These tiles are CSS approximations for previewing. Use the full-resolution originals from locked assets in production, or make your own with the gradient generator.
