06 · Icons

Icons

Phosphor for everyday UI. Netlify Pixel for the moments that should feel unmistakably ours.

Netlify Pixel

Custom icons built from the diamond in our symbol. Save them for intentional, higher branded moments: feature callouts, empty states and marketing modules. Don't use them as everyday UI controls.

UI icons

We use Phosphor Icons at Regular weight, 24px. Don't mix weights or styles. Pair unfamiliar actions with a label, and give every interactive icon an accessible name. Add new icons with the Phosphor Figma plugin; matching packages exist for web, React, Vue, Flutter and more.

npm install @phosphor-icons/web

<i class="ph ph-magnifying-glass" aria-hidden="true"></i>

Third-party marks

The Figma library includes approved marks for social platforms, AI agents, frameworks and Git providers. Use each company's official artwork and follow its brand rules. Never redraw or recolor a partner's mark.
